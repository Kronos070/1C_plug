# ПерУН для 1C:EDT

ИИ-помощник прямо внутри 1C:EDT. Справа от редактора открывается чат: вы задаёте вопрос о конфигурации, а ПерУН отвечает. Он объясняет, что делает процедура, находит, где хранятся данные, пишет документацию и при необходимости меняет код.

## Возможности

- **Чат в стиле современных ИИ-помощников.** Лента сообщений по центру, поле ввода снизу, ответы с оформлением, таблицами и подсветкой кода 1С.
- **Режимы работы:**
  - **Найти** — поиск по конфигурации без изменений.
  - **Объяснить** — разбор кода и документация.
  - **Написать** — изменение кода и метаданных.
  - **Планировать** — проектирование доработок.
- **Вопросы по выделенному коду.** Выделите фрагмент в модуле — над полем ввода появится плашка с именем модуля и номерами строк, и ПерУН будет отвечать именно про этот фрагмент. Если ничего не выделено, к вопросу прикрепляется открытый модуль целиком. Крестик на плашке отменяет прикрепление, даже если код всё ещё выделен. После отправки фрагмент открепляется, новое выделение прикрепится снова.
- **Действия в контекстном меню редактора.** Выделите код, нажмите правую кнопку мыши и выберите **ПерУН →**:
  - **Объяснить код** — разбор того, что делает фрагмент;
  - **Сделать документацию** — помощник сам добавит в модуль комментарии к процедурам и функциям по стандарту 1С;
  - **Найти ошибки** — список проблем с пояснениями, без изменений кода;
  - **Улучшить код** — помощник сам перепишет фрагмент, сохранив его поведение.

  Запрос уходит сразу. Для «Сделать документацию» и «Улучшить код» режим автоматически переключается на «Написать», а перед изменением файла ПерУН спросит разрешение.
- **Выбор модели и глубины рассуждений** прямо в поле ввода.
- **История чатов** в шапке. К любому прошлому диалогу можно вернуться.
- **Копирование** сообщений и блоков кода одной кнопкой.
- **Подтверждение действий.** Перед опасными действиями помощник спрашивает разрешение. Кнопка «Разрешить» разрешает один раз, а стрелка рядом с ней открывает варианты «В этой сессии» и «Всегда». Так же устроена «Отклонить»: в её списке есть «Никогда». Решения «Всегда» и «Никогда» сохраняются, их можно посмотреть и изменить в настройках ПерУН.
- **Живой логотип.** Пиксельная «П» ПерУНа, как в терминальной версии. Пока помощник отвечает, логотип рядом с ответом вращается. Щёлкните по логотипу в шапке или на стартовом экране — будет небольшой сюрприз (закрыть — Esc или щелчок).
- **Тёмная и светлая тема.** По умолчанию чат подстраивается под цвета EDT, тему можно выбрать вручную.
- **Демо-режим** для знакомства с интерфейсом без подключённой модели.

## Что нужно

- 1C:EDT 2024.1 или новее (проверено на 2026.1).
- Установленный агент **ПерУН** (`perun`) или **pi**.
- Доступ к языковой модели: API-ключ провайдера или локальная модель.

## Установка

1. Скопируйте файл `com.example.edtai_1.0.7.jar` в папку `dropins` внутри каталога установки EDT. Если папки нет, создайте её.
   - Linux, установка через 1C:EDT Start: `~/.local/share/1C/1cedtstart/installations/<версия EDT>/1cedt/dropins/`
   - Windows: `%LOCALAPPDATA%\1C\1cedtstart\installations\<версия EDT>\1cedt\dropins\`
2. Перезапустите EDT.
3. Чат появится справа в перспективе «1С:Предприятие». Если его не видно, откройте его так: **Window → Show View → Other… → ПерУН → ПерУН** (в русском интерфейсе: **Окно → Показать панель**). Можно также сбросить перспективу: **Window → Perspective → Reset Perspective**.

## Подключение модели

ПерУН должен знать, к какой модели обращаться. Проще всего настроить это один раз в терминале:

```bash
perun
```

Затем введите `/login` и выберите провайдера. Ключ сохранится, и плагин подхватит его автоматически.

Или прямо в чате плагина: введите `/login`, выберите провайдера и вставьте ключ.

Пока модель не подключена, в поле ввода горит «Модель не выбрана», а на вопрос придёт подсказка с ошибкой.

## Команды

Введите `/` (или `\`) в поле ввода — появится список команд. Он фильтруется по мере набора: `\log` подскажет `/login`. Стрелки выбирают команду, Tab подставляет, Enter выполняет, Esc закрывает.

| Команда | Что делает |
|---|---|
| `/login [провайдер]` | Подключить провайдера по API-ключу: ключ сохранится в настройках ПерУН, агент перезапустится |
| `/model` | Выбрать модель |
| `/thinking` | Глубина рассуждений модели |
| `/new` | Новый чат |
| `/history` | История чатов |
| `/name <название>` | Переименовать чат |
| `/compact [что сохранить]` | Сжать контекст длинного диалога |
| `/session` | Статистика: сообщения, токены, стоимость |
| `/export` | Сохранить чат в HTML |
| `/settings` | Настройки плагина |
| `/help` | Список всех команд |

Чтобы сослаться на файл, введите `@` и начните набирать имя: появится список файлов рабочего каталога (`@ObjectMod` → `@src/…/ObjectModule.bsl`). Выбранный путь вставится в сообщение, и агент прочитает файл сам.

Кроме них в списке появляются команды самого агента: `/mode`, `/permission`, `/doctor`, навыки `/skill:…` и другие.

## Настройки

**Window → Preferences → ПерУН**:

| Параметр | Что делает |
|---|---|
| Команда запуска агента | Пусто — плагин сам найдёт `perun`, а если его нет, то `pi`. Можно указать полный путь к `perun`, `pi` или `perun.bundle.mjs`. |
| Дополнительные аргументы | Передаются агенту при запуске, например `--provider anthropic --model claude-sonnet-4-5`. |
| Рабочий каталог | Папка, в которой работает агент. Пусто — рабочая область EDT. |
| Тема чата | «Как в EDT», «Тёмная» или «Светлая». |
| Всегда разрешать / Никогда не разрешать | Инструменты, для которых вы выбрали «Всегда» или «Никогда» (через запятую). Удалите имя, чтобы помощник снова спрашивал. |
| Демо-режим | Ответы-заглушки без агента: удобно, чтобы посмотреть интерфейс. |

Изменения применяются сразу, перезапускать EDT не нужно.

## Если что-то не работает

- **«Агент недоступен: perun или pi отсутствуют в PATH».** Укажите полный путь к агенту в настройках или включите демо-режим.
- **«No API key found».** Модель не подключена, выполните `/login` (см. выше).
- **Чат пустой или не открывается.** Посмотрите журнал ошибок: **Window → Show View → Error Log**.

## Для разработчиков

Сборка (Maven ставить не нужно, обёртка скачает его сама):

```bash
./mvnw package
```

Готовый плагин появится в `target/com.example.edtai_1.0.7.jar`.

Плагин общается с агентом через `perun --mode rpc`: по stdin/stdout в формате JSONL. Код разложен по слоям:

- `domain` — модели сообщений, моделей ИИ, режимов, событий;
- `application` — сценарии чата (`ChatService`) и порты-интерфейсы;
- `infrastructure` — запуск процесса, RPC-клиент, история сессий, настройки, моки;
- `ui` — вид EDT, мост Java ↔ страница, тема, страница настроек;
- `bootstrap` — сборка зависимостей;
- `src/main/resources/web` — интерфейс чата (HTML, CSS, JS).

Иконки вкладки (`src/main/resources/icons/perun.png` и `perun@2x.png`) — пиксельная «П» ПерУНа. Они генерируются скриптом, сторонние библиотеки не нужны:

```bash
python3 scripts/gen-icons.py
```

Демо-режим целиком лежит в пакете `infrastructure/mock`. Чтобы убрать его, удалите пакет и ветку `demoMode` в `bootstrap/ChatAssembler`.
